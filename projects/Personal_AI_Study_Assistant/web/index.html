List Comprehension in Python

List comprehension is a concise way to create a new list from an existing iterable (like a list, tuple, etc.) using a single line of code. It makes your code shorter and easier to read.

Basic Syntax:
[expression for item in iterable if condition]
Example:
squares = [x**2 for x in range(1, 6)]
print(squares) # Output: [1, 4, 9, 16, 25]
